# ProxVC++

[Requires Halplibe](https://github.com/Turnip-Labs/bta-halplibe)

A expansion on 5Avian's primitive voice chat mod for Better Than Adventure!

Currently Implemented:
* Sound Occlusion/Muffling
* Various Talking indicators
* Movable Hud components
* Audio mixer for individual players

Planned:
* Plugin API for expanding voice chat features i.e
 walkie-talkies, vc groups, or what ever else.
* Sound Reverberation
* Noise Suppression

---

*If this mod fails to start on your server due to a namespace error, try starting it with this command:*

`java -Dfabric.runtimeMappingNamespace=official -Xmx2G -jar fabric-server-launch.jar`

*This namespace error is a result of legacy fabric code. It should be resolved with BTA 8.0 (7.4) or later.*
